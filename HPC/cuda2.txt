What is CUDA?

CUDA (Compute Unified Device Architecture) is NVIDIA’s platform for GPU parallel programming.

It allows:

GPU to solve computational problems using thousands of threads simultaneously
What is Matrix Multiplication?

If:

Matrix A:

1 2
3 4

Matrix B:

5 6
7 8

Then:

Matrix C = A × B

Formula:

C[i][j]=∑k=0 to n−1 A[i][k]×B[k][j]

Example Calculation
C[0][0] = (1×5) + (2×7)
        = 5 + 14
        = 19
Why GPU Good for Matrix Multiplication?

Each matrix element calculation is independent.

Example:

Thread 1 → compute C[0][0]
Thread 2 → compute C[0][1]
Thread 3 → compute C[1][0]

All simultaneously.

Very efficient for GPUs.

CUDA Execution Model
Grid
 ├── Blocks
 │      ├── Threads

Each thread computes one matrix element.
