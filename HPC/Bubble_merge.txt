Bubble Sort Theory

Bubble sort repeatedly:

Compares adjacent elements
Swaps if wrong order

Largest element moves to end after each pass.

Sequential Bubble Sort
Function
void sequentialBubbleSort(vector<int>& arr)
Outer Loop
for(int i = 0; i < n - 1; i++)

Controls number of passes.

Need:
n−1

passes in worst case.

Inner Loop
for(int j = 0; j < n - i - 1; j++)

Compares adjacent elements.

Swap Condition
if(arr[j] > arr[j + 1])

If left element bigger:

swap elements
Example

Array:

5 1 4 2

Pass 1:

5↔1 → 1 5 4 2
5↔4 → 1 4 5 2
5↔2 → 1 4 2 5

Largest element fixed.

Parallel Bubble Sort Theory

Normal bubble sort is hard to parallelize because:

Comparisons depend on neighboring swaps.

Solution:

Odd-Even Transposition Sort
Odd-Even Sort Idea

Two phases:

Even phase
Odd phase
Even Phase

Compare:

(0,1), (2,3), (4,5)

Independent comparisons.

Can run simultaneously.

Odd Phase

Compare:

(1,2), (3,4), (5,6)

Again independent.

Parallel Bubble Sort Function
void parallelBubbleSort(vector<int>& arr)
Outer Loop
for(int i = 0; i < n; i++)

Runs phases repeatedly.

Even Phase
if(i % 2 == 0)
Parallel Loop
#pragma omp parallel for

Distributes comparisons among threads.

Even Index Comparisons
for(int j = 0; j < n - 1; j += 2)

Example:

(0,1)
(2,3)
(4,5)
Odd Phase
for(int j = 1; j < n - 1; j += 2)

Example:

(1,2)
(3,4)
Why Parallel Bubble Sort Works

Each pair comparison independent during phase.

Threads can safely work simultaneously.

Merge Sort Theory

Merge sort uses:

Divide and Conquer

Steps:

Divide array into halves
Sort halves recursively
Merge sorted halves
Merge Sort Visualization

Array:

8 3 7 2

Divide:

8 3 | 7 2

Further:

8 | 3
7 | 2

Merge back:

3 8
2 7

Final merge:

2 3 7 8
Merge Function
Function
void merge(vector<int>& arr, int low, int mid, int high)

Combines two sorted halves.

Temporary Array
vector<int> temp;

Stores merged result.

Two Pointers
i = low
j = mid+1

Used to traverse left and right halves.

Compare Elements
if(arr[i] <= arr[j])

Take smaller element first.

Copy Remaining Elements

After one half finishes:

Copy remaining elements.
Final Copy Back
arr[k] = temp[k-low];

Stores merged sorted array.

Sequential Merge Sort
Recursive Division
sequentialMergeSort(arr, low, mid);

Left half.

sequentialMergeSort(arr, mid + 1, high);

Right half.

Merge Sorted Halves
merge(arr, low, mid, high);
Merge Sort Complexity

O(nlogn)

Much faster than bubble sort for large data.
