What is CUDA?

CUDA (Compute Unified Device Architecture) is NVIDIA’s parallel computing platform.

It allows:

GPU to perform general-purpose computations

instead of only graphics rendering.

Why Use GPU?

CPU:

Few powerful cores
Good for sequential tasks

GPU:

Thousands of smaller cores
Excellent for parallel tasks

Example

Adding two vectors:

A = 1 2 3 4
B = 5 6 7 8

Sequential CPU:

One core adds one element at a time

GPU:

Many threads add elements simultaneously
Important CUDA Concepts
Concept	        Meaning
Host	        CPU
Device	        GPU
Kernel	        Function executed on GPU
Thread	        Smallest execution unit
Block	        Group of threads
Grid	        Collection of blocks

CUDA Execution Model
Grid
 ├── Block 1
 │     ├── Thread 1
 │     ├── Thread 2
 │
 ├── Block 2
 │     ├── Thread 1
 │     ├── Thread 2

Each thread performs small work.

CUDA Kernel
// CUDA Kernel
__global__ void vectorAdd(int *A, int *B, int *C, int n)
What is __global__?

Means:

Function runs on GPU
and called from CPU

This function is called:

Kernel
Kernel Purpose

Adds two vectors element by element.

int i = blockIdx.x * blockDim.x + threadIdx.x;

MOST IMPORTANT CUDA LINE.

Calculates global thread index.

Meaning of Terms
Term	    Meaning
blockIdx.x	Current block number
blockDim.x	Threads per block
threadIdx.x	Thread number inside block

Formula

Global Index=blockIdx.x × blockDim.x + threadIdx.x

Example

Suppose:

blockIdx.x = 2
blockDim.x = 256
threadIdx.x = 10

Then:

i = 2×256 + 10
i = 522

This thread processes:

A[522] + B[522]
Boundary Check
if(i < n)

Prevents out-of-bounds access.

Important because:

Extra threads may exist.
Vector Addition
C[i] = A[i] + B[i];

Each thread adds one element.

Main Function
int main()

Program execution starts here.

Input Vector Size
int n;
cin >> n;
Calculate Memory Size
int size = n * sizeof(int);

Computes total bytes needed.

Example:

n = 5
sizeof(int)=4
size = 20 bytes
Host Vectors (CPU Memory)
int *h_A = new int[n];

h_ means:

Host memory (CPU RAM)
Create Arrays
h_A
h_B
h_C

For:

input vectors
result vector
Input Elements
cin >> h_A[i];

Store vector elements.

Device Pointers
int *d_A, *d_B, *d_C;

d_ means:

Device memory (GPU memory)
GPU Memory Allocation
cudaMalloc((void**)&d_A, size);

Allocates memory on GPU.

Why Needed?

GPU has separate memory.

CPU arrays cannot directly access GPU memory.

Allocate Three GPU Arrays
d_A
d_B
d_C
Copy CPU → GPU
cudaMemcpy(d_A, h_A, size, cudaMemcpyHostToDevice);

Copies vector from:

CPU → GPU
Memory Copy Syntax
cudaMemcpy(destination, source, size, direction)
Threads Per Block
int threadsPerBlock = 256;

Defines:

Each block contains 256 threads
Why 256?

Common efficient CUDA configuration.

Number of Blocks
int blocksPerGrid = (n + threadsPerBlock - 1) / threadsPerBlock;

Calculates required blocks.

Formula

Blocks= n+threadsPerBlock−1 / threadsPerBlock

	​


Why This Formula?

Ensures enough threads for all elements.

Example

If:

n = 1000
threadsPerBlock = 256

Then:

blocksPerGrid = 4

Total threads:

4 × 256 = 1024

Enough for 1000 elements.

Launch Kernel
vectorAdd<<<blocksPerGrid, threadsPerBlock>>>(d_A, d_B, d_C, n);

MOST IMPORTANT CUDA SYNTAX.

Meaning

Launch GPU kernel using:

specified blocks
specified threads
Kernel Launch Structure
kernel<<<blocks, threads>>>(arguments)
Parallel Execution

Thousands of threads execute simultaneously:

Thread 0 → C[0] = A[0]+B[0]
Thread 1 → C[1] = A[1]+B[1]
Thread 2 → C[2] = A[2]+B[2]
Copy GPU → CPU
cudaMemcpy(h_C, d_C, size, cudaMemcpyDeviceToHost);

Copies result:

GPU → CPU
Print Result
cout << h_C[i];

Displays output vector.

Free GPU Memory
cudaFree(d_A);

Releases GPU memory.

Important to avoid memory leaks.

Free CPU Memory
delete[] h_A;

Releases dynamically allocated CPU memory.

Example Execution

Input:

A = 1 2 3 4
B = 5 6 7 8

GPU threads:

Thread 0 → 1+5 = 6
Thread 1 → 2+6 = 8
Thread 2 → 3+7 = 10
Thread 3 → 4+8 = 12

Output:

6 8 10 12
